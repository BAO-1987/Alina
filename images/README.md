# Зображення для сайту

Ця папка містить всі зображення для сайту порятунку тварин.

## Необхідні зображення:

### Основні:
- `logo.svg` - Логотип організації (вже є)

### Hero секція:
- `hero.jpg` - Головне зображення (рекомендований розмір: 800x600px)

### Термінові збори:
- `urgent-1.jpg` - Зображення для першого збору
- `urgent-2.jpg` - Зображення для другого збору
- `urgent-3.jpg` - Зображення для третього збору

### Іконки:
- `icon-donate.svg` - Іконка донату
- `icon-volunteer.svg` - Іконка волонтерства
- `icon-foster.svg` - Іконка перетримки
- `icon-supplies.svg` - Іконка корму та ліків

### Історії порятунку:
- `story-1.jpg` - Перша історія
- `story-2.jpg` - Друга історія
- `story-3.jpg` - Третя історія

### Партнери:
- `partner-1.png` - Логотип партнера 1
- `partner-2.png` - Логотип партнера 2
- `partner-3.png` - Логотип партнера 3
- `partner-4.png` - Логотип партнера 4
- `partner-5.png` - Логотип партнера 5

## Примітки:
- Всі зображення мають бути оптимізовані для веб-використання
- Рекомендований формат: JPG для фото, PNG для логотипів, SVG для іконок
- Розміри зображень мають відповідати дизайну (1440px ширина контейнера)
